BIRTHDAY WEBSITE FOR DODI NTUT ♡

CARA MEMBUKA:
1. Ekstrak file ZIP ini.
2. Pastikan folder assets tetap satu folder dengan index.html.
3. Buka index.html di browser untuk mencoba (sebagian browser HP mungkin membatasi audio dari file lokal).
4. Untuk membagikan sebagai link, upload SELURUH isi folder ke layanan hosting statis seperti GitHub Pages atau Netlify.

CARA EDIT PALING GAMPANG:
- Buka index.html dengan editor teks/kode.
- Cari teks yang ingin diganti (misalnya "Dodi Ntut", "HAPPY BIRTHDAY", atau surat pada bagian id="letterText").
- Foto: ganti file di folder assets dengan foto baru memakai nama file yang sama, atau ubah nama file pada atribut src di index.html.
- Lagu: ganti assets/seasons.mp3 dengan file audio yang kamu pilih, beri nama seasons.mp3.
- Jangan hapus folder assets atau ubah susunan foldernya.

CATATAN:
- Lagu mulai setelah tombol pembuka ditekan karena browser biasanya tidak mengizinkan autoplay sebelum interaksi.
- Isi ucapan disimpan apa adanya sesuai pesan yang kamu kirim, termasuk gaya bahasa aslinya.
